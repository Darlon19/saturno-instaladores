# Saturno 1 — instaladores

Downloads oficiais da série Saturno, da Damara Sistemas LTDA.

**Ainda não há versão liberada para novos clientes nesta página.**
A versão 2026.10.25.1 está em preparação. Sua publicação depende da conclusão
da análise de detecção do Microsoft Defender e da validação final em Windows limpo.

Quando houver uma versão liberada, baixe os arquivos em [Releases](../../releases).
Os instaladores ficam nos anexos da versão; o ZIP automático de código-fonte não é um instalador.

O pacote inicial conterá:
- Instalador Windows x64 com opções Servidor da empresa ou Somente cliente.
- Banco inicial separado, com estrutura e registros essenciais, sem dados de empresas.
- Arquivo de hashes SHA-256 para conferir os downloads.

Novos clientes cadastram empresa e administrador no primeiro acesso e solicitam autorização.
Computadores cliente precisam da conexão fornecida pelo suporte.
O banco inicial é somente para banco novo e vazio; não deve substituir bancos em uso.

Este repositório não contém o código-fonte do ERP nem backups de clientes.
